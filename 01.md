## Count of positives / sum of negatives

```py
def count_positives_sum_negatives(arr):
    pos = sum(1 for x in arr if x > 0)
    neg = sum(x for x in arr if x < 0)
    return [pos, neg] if arr else []
```

## Calculate BMI

```py
def bmi(weight, height):
    b = weight / (height * height)
    
    if b <= 18.5:
        return "Underweight"
    elif b <= 25:
        return "Normal"
    elif b <= 30:
        return "Overweight"
    else:
        return "Obese"
```
